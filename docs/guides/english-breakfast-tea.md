# English breakfast tea

{% hint style="info" %}
This is a test.
{% endhint %}

A classic English breakfast tea is strong, full-bodied, and best made with freshly boiled water. Follow these steps for a reliable cup every time.

{% stepper %}
{% step %}
#### Boil fresh water

Fill the kettle with fresh cold water and bring it to a full rolling boil. Avoid re-boiling water that has already cooled — it can taste flat.

{% hint style="warning" %}
Use freshly drawn water, not water that has been sitting in the kettle overnight.
{% endhint %}
{% endstep %}

{% step %}
#### Warm the teapot (optional)

Pour a little boiling water into your teapot, swirl it around, then discard. This helps keep the brew hot while the tea steeps.
{% endstep %}

{% step %}
#### Add the tea

Place one tea bag per cup into the teapot, plus one extra for the pot — or use about one teaspoon of loose-leaf tea per cup, plus one for the pot, in an infuser.

For a single mug, one tea bag is enough.
{% endstep %}

{% step %}
#### Pour and steep

Pour boiling water over the tea. Cover the teapot and let it steep for **3 to 5 minutes**. English breakfast is robust; longer brewing makes it stronger and more bitter.
{% endstep %}

{% step %}
#### Serve

Pour the tea into cups. Add milk if you like — many people pour milk into the cup first, then add tea. Sweeten with sugar only if you prefer.

Drink while hot.
{% endstep %}
{% endstepper %}
